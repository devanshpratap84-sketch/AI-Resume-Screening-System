# AI-Based Resume Screening System

An AI-based resume screening application built using Python, Streamlit, and machine learning techniques.

## Live Demo
https://ai-resume-screening-system-v79qkvkp7jdvgnuca2mamp.streamlit.app/

## Features
- Upload PDF resumes
- Compare resumes with a job description
- Calculate resume match scores
- Identify matched skills
- Display screening results
- Download results as CSV

## Technologies Used
- Python
- Streamlit
- Pandas
- PyPDF2
- Scikit-learn
- TF-IDF and cosine similarity

## How to Run Locally
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.
